# PixieCore plugin authoring examples

These four complete, offline examples show every public managed-plugin component
kind. Each project owns its named TypeScript and YAML entries, compiled JavaScript,
implementation under `src/`, and a plugin-owned test under `tests/`.

- `sample-role`: agent role
- `sample-decorator`: output decorator
- `sample-tool`: tool
- `sample-provider`: provider factory

They are equivalent to projects generated by:

```bash
pixiecore plugin create ./sample-tool --id=example.sample-tool --kind=tool
pixiecore plugin validate ./sample-tool
pixiecore plugin test ./sample-tool
```

See [the authoring guide](../../docs/plugins/plugin-authoring.md) for installation,
activation, integrity metadata, signing, compatibility, and rollback.
