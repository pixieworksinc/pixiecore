# POP request for comments index

POP RFCs are public, durable proposals for normative specification,
conformance, governance, and project-name usage changes. The authoritative
process, review periods, quorum, and compatibility rules are defined in
[`docs/specification/pop-governance.md`](../specification/pop-governance.md).

## Authoring

Copy [`0000-template.md`](0000-template.md) to the next four-digit number and a
short lowercase slug. Do not reuse identifiers. A draft has no normative
effect, and an accepted RFC changes only the artifacts explicitly listed in
its acceptance record.
