Documentation / docs/rfcs/0000-template.md

POP-RFC-NNNN: Proposal title

  • Status: draft
  • Authors: GitHub accounts or stable public identities
  • Change class: editorial | compatible normative | incompatible normative | governance or name usage
  • Created: YYYY-MM-DD
  • Proposed review start: not started
  • Decision date: not decided
  • Discussion: issue or pull-request link
  • Affected artifacts: exact documents, identifiers, schemas, or fixtures
  • Conflicts and recusals: none disclosed
  • Supersedes: none
  • Superseded by: none

Summary

State the proposed rule and its user-visible purpose.

Motivation and scope

Describe the problem, included behavior, and explicitly excluded behavior.

Specification

Write the proposed normative behavior precisely enough for independent implementations to agree.

Compatibility and migration

Identify preserved behavior, breaking behavior, deprecation, migration, rollback, and version changes.

Security, privacy, cost, and interoperability

Describe each impact or write none identified with a rationale.

Conformance and independent evidence

List schemas, fixtures, negative cases, implementation results, and independent validator or implementation evidence.

Alternatives

Record viable alternatives and why they were not selected.

Review record

Record material revisions, objections, responses, and review-period restarts.
