# PixieCore maintainers

This file is the authoritative public roster for project roles and release
authority.

| GitHub account | Role | Merge authority | Release authority |
|---|---|---:|---:|
| `@naoi` | Project Lead and Maintainer | Yes | Yes |

## Membership changes

A maintainer appointment, role change, resignation, or removal requires a
public decision record under [`docs/decisions/`](docs/decisions/README.md).
Emergency access revocation may happen first when necessary to protect users or
project assets, but the non-sensitive rationale and resulting roster change
must be recorded promptly.

The project currently has a single release-capable maintainer. This is an
explicit continuity risk, not a claim of distributed ownership. Expanding to at
least two release-capable maintainers remains a tracked governance objective.
